# Требования и решения до реализации

Источник: [оригинал задания](original-task.md), прочитан целиком. Дополнительные требования пользователя из запроса 16 октября 2026 учтены в реализации и проверках.

- Go backend; PostgreSQL; браузерный JavaScript без сборщика и зависимостей. Go раздаёт панель и REST API из одного бинарника.
- Сущность расхода содержит ровно восемь полей из задания. Семь категорий записываются по-русски как в оригинале.
- Одна валюта RUB; до двух десятичных знаков; более точный ввод отклоняется вместо округления. В Go — целые копейки, в PostgreSQL — NUMERIC(11,2), в JSON — десятичная строка.
- `spent_at` — календарная дата. Время создания/изменения — TIMESTAMPTZ. «Вчера», текущая неделя с понедельника и месяц рассчитываются сервером в APP_TIMEZONE.
- Настоящий агент через настраиваемый OpenAI-совместимый Chat Completions API со structured tool calls. Никаких внешних инструментов исполнения SQL, кода, HTTP или MCP.
- Все инструменты бота работают через серверную сессию с владельцем из Telegram update. Административный REST API не используется агентом.
- При неоднозначном поиске изменения/удаления — уточнение ID. Одна изменяемая/удаляемая запись за сообщение. ID выбирается текущим сообщением пользователя; модель не может угадывать его из списка.
- Telegram long polling, только личные текстовые чаты. Одна реплика агента — транзакция; повтор update возвращает сохранённый ответ; повтор одинакового инструмента внутри реплики возвращает закешированный результат.
- Панель без авторизации управляет всеми расходами. Единственный опубликованный порт привязан к localhost, БД не публикует порт. Это локальное тестовое приложение.
- Повторный ввод одинакового текста новым Telegram сообщением считается новым намерением; глобальная дедупликация по тексту скрыла бы реальные одинаковые покупки.
- Пагинация 20 строк по умолчанию, максимум 100. Сортировка списка по spent_at DESC, id DESC; «последний» означает последний созданный расход текущего пользователя.
- Непредоставленные ключи не подменяются fake LLM: без них доступна полноценная панель/API; реальный бот включается после настройки env.
