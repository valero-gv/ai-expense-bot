# Тестовое задание: ИИ-бот учёта расходов

Нужно сделать сервис учёта семейных расходов. Член семьи пишет боту в Telegram «кофе 350», и трата сохраняется: бот сам определяет сумму, категорию и дату.

Сервис состоит из двух частей:

- **Telegram-бот с ИИ-агентом.** Понимает обычный текст: добавляет, показывает, изменяет и удаляет траты. Каждому члену семьи доступны только его траты.
- **Веб-панель для главы семьи.** Показывает траты всех членов семьи и позволяет их редактировать. Авторизация не нужна.

## Модель данных

Сущность Трата:

| Поле | Смысл |
|---|---|
| `id` | идентификатор траты |
| `user_id` | Telegram ID владельца |
| `amount` | сумма |
| `category` | категория: еда, транспорт, жильё, развлечения, здоровье, покупки, другое |
| `spent_at` | дата траты |
| `comment` | необязательный комментарий |
| `created_at`, `updated_at` | время создания и изменения |

## Telegram-бот

Бот реализует CRUD над тратами пользователя на естественном языке, без кнопок и команд:

- добавить: «кофе 350», «такси 1200 вчера»;
- посмотреть: «сколько потратил на еду в этом месяце», «покажи траты за неделю»;
- изменить: «последнее было не 350, а 450»;
- удалить: «удали такси».

Чужие траты в боте недоступны.

## Веб-панель

СRUD над тратами всех членов семьи: список с фильтром по члену семьи, периоду и категории, создание, редактирование, удаление. Панель работает с бэкендом через REST API.

## Требования

- Бэкенд на Go, фронтенд на любом стеке.
- Приложение запускается со всеми зависимостями через один `docker compose`.
- Доступ к LLM настраивается через конфиг.
